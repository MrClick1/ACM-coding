# 米哈游程序岗专项题单

## 使用规则

这套题和普通 LeetCode 刷法不同。

每道题都要求：

- [ ] **先隐藏题目标签**，自己判断属于什么算法
- [ ] 先看数据范围，再决定时间复杂度
- [ ] 至少独立思考 20～30 分钟
- [ ] 使用 C++ 完成
- [ ] 真题按照 ACM/OJ 模式完整处理输入输出
- [ ] LeetCode AC 后，挑重点题自己补一个 `main()`，改成 ACM 模式
- [ ] 做完记录“我为什么没想到”，而不只是记录答案

目标不是背模板，而是训练：

**题面 → 建模 → 数据范围 → 算法 → 实现**

# 错题记录模板

每道没独立做出来的题，只记录下面五件事：

1. **题型：**
2. **第一反应是什么：**
3. **正确模型是什么：**
4. **为什么当时没想到：**
5. **下次看到什么特征应该想到这个算法：**

例如：

> 题型：单调栈
> 第一反应：双重循环
> 正确模型：维护单调递减栈
> 没想到原因：只关注了“比较所有数对”
> 识别信号：寻找左右第一个更大/更小元素、要求 O(n)

这个过程比简单写：

> “不会单调栈。”

有用得多。
