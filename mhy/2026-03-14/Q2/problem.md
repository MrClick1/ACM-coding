# Q2 - 错峰站位（删除最少元素形成摆动序列）

> 来源：[牛客改编题帖](https://www.nowcoder.com/discuss/862663237941067776) · 题单见 [../../README.md](../../README.md)

## 题目描述

K 小姐正在给一组演员安排舞台站位。第 i 位演员的站位高度记为 h[i]。

如果一段站位序列满足下面两个条件，就称它是“错峰站位”：

1. 对于每个中间位置，当前演员的高度要么严格高于左右两侧，要么严格低于左右两侧；
2. 任意相邻两位演员的高度都不能相等。

等价地说：相邻高度差的正负号必须严格交替（如 + - + - ... 或 - + - + ...）。长度为 1 的序列天然满足条件；长度为 2 的序列只要两人高度不相等也满足。

现在可以从原序列中删除若干位演员，剩下的演员保持原有相对顺序不变。请计算最少要删除多少人，才能让剩余队形变成“错峰站位”。

## 输入格式

第一行输入一个整数 n，表示演员人数。

第二行输入 n 个整数 h[1], h[2], ..., h[n]，表示每位演员的站位高度。

## 输出格式

输出一个整数，表示最少删除人数。

## 样例

### 样例 1

输入：

```text
7
1 3 1 4 5 2 0
```

输出：

```text
2
```

解释：删除高度 5 和 0 两位演员后，剩余序列 1, 3, 1, 4, 2 的相邻差值正负交替（+ - + -），满足要求。

### 样例 2

输入：

```text
3
2 2 2
```

输出：

```text
2
```

解释：所有人高度都相同，任意相邻两人高度相等，不可能保留长度 ≥ 2 的合法序列，最优只能保留 1 人，因此需要删除 2 人。

## 数据范围

- 1 ≤ n ≤ 10^5
- 0 ≤ h[i] ≤ 10^9

## 注意事项

- 只要求剩余序列满足条件，不要求保留的两人在原序列中相邻。
- n = 1 时不需要删除任何人；n = 2 且两人高度不同时也不需要删除。
