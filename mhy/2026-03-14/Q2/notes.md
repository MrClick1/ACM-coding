# 复盘

## 我的第一反应

以前见过类似题（LeetCode 376 摆动序列），有直觉：删除递增区间中间的元素、保留两头的，但不知道怎么写代码。

## 最初考虑的算法

方向是“保留最长合法子序列”，但卡在怎么把“去掉中间、保留两头”的直觉转成程序；还一度混淆 keep = 1 到底代表第一个人还是最后一个人。

## 卡住的位置

- 从直觉到代码的转换：不知道怎么用一次扫描实现“每段走势留一个端点”。
- 对计数含义理解不透：keep 初始 1 代表第一个人；每次 keep++ 代表“又有一段同向走势”，对应保留该段走势的终点，而不是触发时刻那个下标。

## 正确模型

把数组转成相邻差值符号序列（+ / - / 0），忽略 0；连续同号合并成“方向块”。最多保留人数 = 1（第一个人）+ 块数，最少删除 = n - keep。代码只需一次扫描：pre 记录上一块符号，遇到第一次非零差值或符号变化就 keep++。

为什么贪心成立：一段单调走势里，中间点永远不如终点有用——上升段里终点最高，对后续下降最有利；下降段对称。所以每段走势只留一个终点即可。

## 为什么当时没有想到

- 一直想“删哪些人”，没有转换成“最多能留几个人”。
- 没想到把数组压缩成差值符号的“趋势序列”，再数方向变化次数。

## 下次看到什么特征应该想到这个算法

- “删除最少使剩余序列满足相邻关系” → 转换成“保留最长合法子序列”。
- “相邻差值正负交替 / 摆动序列” → 先画差值符号，数方向块 / 转折点。
- 递增、递减区间中间元素“没用”的直觉 → 每段走势只留终点。

## 时间复杂度

O(n)，一次扫描。

## 空间复杂度

O(1)，只记录 pre 和 keep；若先构造差值符号数组再数块，则为 O(n)。
