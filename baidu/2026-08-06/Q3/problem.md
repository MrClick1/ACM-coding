# Q3 - 报文置换归位

> ⚠️ 非官方原题：以下题面根据 2026-08-06 百度算法岗公开回忆整理，业务背景和表述可能与原卷存在差异。
> 来源：[牛客公开整理](https://www.nowcoder.com/discuss/915065176213192704?sourceSSR=post) · 题单见 [../../README.md](../../README.md)

## 题目描述

给定一个长度为 n 的小写字母字符串 u，以及一个长度为 n 的排列 p。

下标从 1 开始。一次操作会生成一个新的字符串 w，其中：

w[i] = u[p[i]]（1 ≤ i ≤ n）

完成一次操作后，令 u = w，之后继续使用同一个排列执行下一次操作。

请计算最小的正整数 k，使得恰好执行 k 次操作后，字符串恢复为最初的内容。由于答案可能很大，请输出：

k mod (10^9 + 7)

## 输入格式

第一行输入一个整数 n。

第二行输入一个长度为 n 的、仅由小写英文字母组成的字符串 u。

第三行输入 n 个整数 p1, p2, ..., pn，表示一个排列。

## 输出格式

输出一个整数，表示最少操作次数对 10^9 + 7 取模后的结果。

## 样例

### 样例 1

输入：

```text
2
xy
2 1
```

输出：

```text
2
```

解释：操作一次得到 `yx`，再操作一次恢复为 `xy`。

### 样例 2

输入：

```text
3
zzz
2 3 1
```

输出：

```text
1
```

解释：虽然排列形成一个长度为 3 的环，但三个位置的字符相同，执行一次后字符串已经与原串相同。

### 样例 3

输入：

```text
5
hello
2 3 4 5 1
```

输出：

```text
5
```

## 数据范围

- 1 ≤ n ≤ 2×10^5
- 字符串 u 仅包含小写英文字母
- 1 ≤ p[i] ≤ n
- p 是一个排列，即 1, 2, ..., n 各出现恰好一次

## 注意事项

- 求的是字符串内容第一次恢复，而不一定是所有位置完成一个完整排列周期。
- 即使一个置换环很长，环上字符存在重复时也可能更早恢复。
- 真正的 k 可能超过 64 位整数范围。
- 不能先把各部分周期取模后再直接计算普通最小公倍数。
