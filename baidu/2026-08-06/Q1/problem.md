# Q1 - 波动贡献最大化

> ⚠️ 非官方原题：以下题面根据 2026-08-06 百度算法岗公开回忆整理，业务背景和表述可能与原卷存在差异。
> 来源：[牛客公开整理](https://www.nowcoder.com/discuss/915065176213192704?sourceSSR=post) · 题单见 [../../README.md](../../README.md)

## 题目描述

给定一个长度为 n 的整数序列 v1, v2, ..., vn。

你需要把整个序列划分为若干个非空、首尾相接的连续子段。每个元素必须恰好属于一个子段，且不能改变元素顺序。

对于子段 vL, vL+1, ..., vR，定义：

- 子段长度为 R - L + 1；
- 子段波动值为该段最大值减最小值；
- 子段贡献为

H(L,R) = (max(vL..vR) - min(vL..vR)) × (R - L + 1)

请计算所有合法划分中，各子段贡献之和的最大值。

## 输入格式

第一行输入一个整数 n。

第二行输入 n 个整数 v1, v2, ..., vn。

## 输出格式

输出一个非负整数，表示最大总贡献。

## 样例

### 样例 1

输入：

```text
3
2 5 1
```

输出：

```text
12
```

解释：把整个数组作为一个子段，其贡献为 (5-1)×3 = 12。

### 样例 2

输入：

```text
4
1 5 2 4
```

输出：

```text
16
```

解释：把整个数组作为一个子段，其贡献为 (5-1)×4 = 16。

### 样例 3

输入：

```text
1
100
```

输出：

```text
0
```

## 数据范围

- 1 ≤ n ≤ 3×10^5
- 1 ≤ v[i] ≤ 10^9

## 注意事项

- 划分后的所有子段必须完整覆盖原序列。
- 单元素子段的最大值和最小值相同，因此贡献为 0。
- 答案可能超过 32 位整数范围，请使用 64 位整数。
- 题目只要求输出最大贡献，不要求输出具体划分。
