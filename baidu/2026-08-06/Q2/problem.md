# Q2 - 最小对冲值

> ⚠️ 非官方原题：以下题面根据 2026-08-06 百度算法岗公开回忆整理，业务背景和表述可能与原卷存在差异。
> 来源：[牛客公开整理](https://www.nowcoder.com/discuss/915065176213192704?sourceSSR=post) · 题单见 [../../README.md](../../README.md)

## 题目描述

把一个非负整数额度 \(m\) 拆成两份。

你可以任选一个整数 \(y\)，满足 \(0\le y\le m\)，另一份为 \(m-y\)。定义本次拆分的对冲值为：

\[
G(y)=y\oplus(m-y)
\]

其中 \(\oplus\) 表示按位异或。

现在给定 \(q\) 个额度。对于每个 \(m\)，请计算能够取得的最小对冲值：

\[
\min_{0\le y\le m}\left(y\oplus(m-y)\right)
\]

## 输入格式

第一行输入一个整数 \(q\)，表示询问数量。

接下来 \(q\) 行，每行输入一个整数 \(m\)。

## 输出格式

输出 \(q\) 行。对于每个询问，输出对应的最小对冲值。

## 样例

### 样例 1

输入：

```text
3
4
5
11
```

输出：

```text
0
1
3
```

解释：

- \(m=4\) 时可以取 \(y=2\)，得到 \(2\oplus2=0\)；
- \(m=5\) 时可以取 \(y=2\)，得到 \(2\oplus3=1\)；
- \(m=11\) 时可以取 \(y=4\)，得到 \(4\oplus7=3\)。

### 样例 2

输入：

```text
2
2
7
```

输出：

```text
0
7
```

## 数据范围

- \(1 \le q \le 10^5\)
- \(1 \le m \le 10^{18}\)

## 注意事项

- 每个询问相互独立。
- \(y=0\) 和 \(y=m\) 都是允许的。
- \(m\) 最大可达 \(10^{18}\)，无法枚举所有拆分方案。
- 输入和按位运算必须使用能够容纳 64 位非负整数的类型。
