# Q1 - 阈值分界总和逼近

> 来源：[公开整理](https://onefly.top/zero2Leetcode/04_real_interviews/baidu/algo-20260813/) · 题单见 [../../README.md](../../README.md)

## 题目描述

给定 n 个元素，第 i 个元素包含三个整数：

- 判定值 h[i]；
- 低位值 l[i]；
- 高位值 r[i]。

你需要选择一个任意整数阈值 T。第 i 个元素的最终取值 v[i] 按以下规则确定：

- 若 h[i] < T，则 v[i] = l[i]；
- 若 h[i] ≥ T，则 v[i] = r[i]。

设最终总和为

V(T) = v1 + v2 + ... + vn

给定目标整数 S，请计算所有整数阈值 T 中，|V(T) - S| 的最小值。

## 输入格式

第一行输入一个整数 n，表示元素个数。

第二行输入一个整数 S，表示目标总和。

接下来 n 行，每行输入三个整数 h[i], l[i], r[i]。

## 输出格式

输出一个整数，表示 |V(T) - S| 的最小可能值。

## 样例

### 样例 1

输入：

```text
3
10
1 5 100
2 3 50
3 1 20
```

输出：

```text
1
```

解释：当 T > 3 时，三个元素都取低位值，总和为 5 + 3 + 1 = 9，与目标值 10 相差 1。

### 样例 2

输入：

```text
2
0
5 -3 4
7 3 -4
```

输出：

```text
0
```

解释：当 T ≤ 5 时，两个元素都取高位值，总和为 4 + (-4) = 0；当 T > 7 时，两个元素都取低位值，总和也为 -3 + 3 = 0。

## 数据范围

本练习版使用以下约束：

- 1 ≤ n ≤ 2×10^5
- -10^9 ≤ S, h[i], l[i], r[i] ≤ 10^9

## 注意事项

- 阈值 T 可以是任意整数，不要求出现在输入中。
- 当多个元素的 h[i] 相同时，它们对同一个阈值的判断结果必然相同。
- l[i]、r[i] 和 S 都可能为负数。
- 总和与答案可能超过 32 位整数范围，请使用 64 位整数。
