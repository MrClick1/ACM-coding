# Q2 - 排列子数组和最大化

> ⚠️ 非官方原题：以下题面根据 2026-08-13 百度算法岗公开回忆整理；原始材料未给出完整数据范围，本练习版按公开解法代码所示规模补全。
> 来源：[公开整理](https://onefly.top/zero2Leetcode/04_real_interviews/baidu/algo-20260813/) · 题单见 [../../README.md](../../README.md)

## 题目描述

给定一个整数 \(n\)，请构造一个长度为 \(n\) 的排列 \(p\)。

长度为 \(n\) 的排列由 \(1,2,\ldots,n\) 各出现恰好一次组成。

对于排列的每一个非空连续子数组 \(p_L,p_{L+1},\ldots,p_R\)，定义它的价值为其中所有元素之和：

\[
value(L,R)=\sum_{i=L}^{R}p_i
\]

整个排列的总价值为所有非空连续子数组价值之和：

\[
F(p)=\sum_{1\le L\le R\le n} value(L,R)
\]

请最大化 \(F(p)\)，输出最大总价值对 \(10^9+7\) 取模后的结果，并输出任意一个达到最大值的排列。

## 输入格式

输入一行一个整数 \(n\)。

## 输出格式

第一行输出最大总价值对 \(10^9+7\) 取模后的结果。

第二行输出 \(n\) 个整数，表示任意一个达到最大总价值的排列。

## 样例

### 样例 1

输入：

```text
3
```

输出：

```text
21
2 3 1
```

解释：排列 \([2,3,1]\) 的六个非空连续子数组之和依次为 \(2,3,1,5,4,6\)，总价值为 21。

### 样例 2

输入：

```text
4
```

输出：

```text
54
2 4 3 1
```

解释：该排列可以达到最大总价值 54。最优排列不唯一，因此合法输出可能与样例不同。

### 样例 3

输入：

```text
1
```

输出：

```text
1
1
```

## 数据范围

本练习版使用以下约束：

- \(1 \le n \le 3\times10^5\)
- 模数固定为 \(10^9+7\)

## 注意事项

- 最大化的是取模前的真实总价值，不能用取模后的大小判断方案优劣。
- 输出的第二行必须是 \(1\) 到 \(n\) 的合法排列。
- 最优排列可能不唯一，输出任意一个即可。
- 计算位置贡献时可能出现超过 32 位整数范围的中间值。
