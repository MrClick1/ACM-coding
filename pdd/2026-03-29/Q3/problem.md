# Q3 - 两个背包装奖品（排序 + 双指针 + 后缀最大值）

> ⚠️ 非官方原题：拼多多原题未公开。以下为根据题单概述与网络公开信息重构的练习版题目，样例与数据范围为构造值；若之后找到官方原题可替换本文件。
> 来源：题单见 [../../README.md](../../README.md)

## 题目描述

小 P 有一排 n 件奖品，编号 1..n。数据保证奖品已经按趣味值**非降序**排列：a[1] ≤ a[2] ≤ ... ≤ a[n]。

现在有两个空背包，规则如下：

1. 每个背包必须装**连续的一段**奖品（段内至少 1 件），两段互不重叠（同一件奖品不能装进两个背包）。
2. 一个背包内任意两件奖品的趣味值之差不能超过 k，等价于段内最大趣味值与最小趣味值之差 ≤ k。

请你计算：两个背包**总共最多能装多少件奖品**。

## 输入格式

第一行两个整数 n, k。

第二行 n 个整数 a[1], a[2], ..., a[n]，已按非降序给出。

## 输出格式

输出一个整数，表示两个背包最多能装的总件数。

## 样例

### 样例 1

输入：

```text
6 2
1 1 2 3 5 6
```

输出：

```text
6
```

解释：第一段取 [1, 1, 2, 3]（极差 3 - 1 = 2 ≤ k），第二段取 [5, 6]（极差 1 ≤ k），两段共 4 + 2 = 6 件，即全部奖品。

### 样例 2

输入：

```text
5 3
1 3 6 10 15
```

输出：

```text
3
```

解释：合法连续段最长只有长度 2（如 [1, 3] 或 [3, 6]）。候选长度为 2 的段 [1, 3]（位置 1..2）和 [3, 6]（位置 2..3）共享位置 2，不能同时选，因此最多一个长度 2 的段再加一个长度 1 的段，共 2 + 1 = 3 件。

## 数据范围

- 2 ≤ n ≤ 10^5
- 0 ≤ a[i], k ≤ 10^9
- 输入保证 a 非降序

## 注意事项

- 两个背包都必须装（每段至少 1 件），且两段互不重叠。
- 段内条件只看极差：max - min ≤ k。
- 不要被“背包”二字误导成 0/1 背包问题。
