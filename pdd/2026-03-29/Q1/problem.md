# Q1 - 货运巡线（模拟）

> ⚠️ 非官方原题：拼多多原题未公开。以下为根据题单概述与网络公开信息重构的练习版题目，样例与数据范围为构造值；若之后找到官方原题可替换本文件。
> 来源：题单见 [../../README.md](../../README.md)

## 题目描述

一辆货车从仓库出发执行沿线配送任务。出发时车上已经有 initialWeight 吨货物，货车能承受的最大载重为 maxWeight 吨。载重在途中任何时刻都必须满足 0 ≤ 载重 ≤ maxWeight（含端点）。

沿线按顺序有 n 个站点，编号 1..n，货车必须按顺序经过每个站点。第 i 个站点会依次发生两件事：

1. 卸货 u_i 吨（卸货后的载重不能小于 0）；
2. 装货 v_i 吨（装货后的载重不能超过 maxWeight）。

如果全程都能满足载重限制，则任务可行；否则任务失败。

请你判断任务是否可行。若可行，输出 YES 和最终载重；若不可行，输出 NO。

## 输入格式

第一行三个整数 initialWeight, maxWeight, n。

接下来 n 行，每行两个整数 u_i, v_i，表示第 i 个站点先卸 u_i 吨、再装 v_i 吨。

## 输出格式

若可行，输出一行：`YES 最终载重`；否则输出一行：`NO`。

## 样例

### 样例 1

输入：

```text
5 10 2
2 3
1 4
```

输出：

```text
YES 9
```

解释：初始载重 5。站点 1：卸 2 后为 3（合法），装 3 后为 6（≤ 10，合法）。站点 2：卸 1 后为 5（合法），装 4 后为 9（≤ 10，合法）。最终载重 9。

### 样例 2

输入：

```text
8 10 2
5 9
0 0
```

输出：

```text
NO
```

解释：初始载重 8。站点 1 卸 5 后为 3，装 9 后为 12，超过 maxWeight = 10，任务失败。

## 数据范围

- 1 ≤ n ≤ 10^5
- 0 ≤ initialWeight ≤ maxWeight ≤ 10^9
- 0 ≤ u_i, v_i ≤ 10^9

## 注意事项

- 每站固定顺序：先卸后装。
- 卸货时载重不能为负，装货后不能超过 maxWeight，两者都要检查。
- 全程载重可能超过 32 位整数范围，注意使用 64 位类型。
