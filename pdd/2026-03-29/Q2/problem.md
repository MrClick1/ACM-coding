# Q2 - 排课计划（DAG / 森林最长路径）

> ⚠️ 非官方原题：拼多多原题未公开。以下为根据题单概述与网络公开信息重构的练习版题目，样例与数据范围为构造值；若之后找到官方原题可替换本文件。
> 来源：题单见 [../../README.md](../../README.md)

## 题目描述

小 P 所在的学校有 n 门课程，编号 1..n。为了简化，学校规定**每门课程至多只有一个直接先修课程**。

现在给出每门课的直接先修课程编号 pre[i]（若 pre[i] = 0 表示该课程没有先修课程），并保证依赖关系不会成环。

每学期可以同时修任意多门课程，但修一门课之前必须已经修完它的全部先修课程（包括间接先修）。一门课在一个学期内完成。

请你计算：修完所有课程**最少需要多少个学期**。

## 输入格式

第一行一个整数 n。

第二行 n 个整数 pre[1], pre[2], ..., pre[n]，其中 pre[i] 表示课程 i 的直接先修课程编号，0 表示无先修。

## 输出格式

输出一个整数，表示最少需要的学期数。

## 样例

### 样例 1

输入：

```text
3
0 1 2
```

输出：

```text
3
```

解释：课程 1 没有先修，课程 2 需要先修课程 1，课程 3 需要先修课程 2。依赖链 1 → 2 → 3 长度为 3，因此需要 3 个学期。

### 样例 2

输入：

```text
5
0 1 1 2 0
```

输出：

```text
3
```

解释：课程 1、5 没有先修；课程 2、3 直接依赖课程 1；课程 4 依赖课程 2。最长依赖链是 1 → 2 → 4，长度为 3，因此需要 3 个学期（第 1 学期修 1、5，第 2 学期修 2、3，第 3 学期修 4）。

## 数据范围

- 1 ≤ n ≤ 10^5
- 0 ≤ pre[i] ≤ n
- 输入保证依赖关系无环

## 注意事项

- 每门课最多只有一个直接先修课程，但可以有多个后继课程，整个结构是若干棵树/链组成的森林。
- 一学期可以修多门互不依赖的课程。
- 最少学期数等于最长依赖链的课程数。
