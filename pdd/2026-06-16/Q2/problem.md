# Q2 - 删除数组（DP + 哈希优化）

> ⚠️ 非官方原题：拼多多原题未公开。以下为根据题单概述与网络公开信息重构的练习版题目，样例与数据范围为构造值；若之后找到官方原题可替换本文件。
> 来源：题单见 [../../README.md](../../README.md)

## 题目描述

小 P 有一个长度为 n 的数组 a[1..n]。每次操作可以这样做：

1. 选择两个下标 i ≤ j，要求 a[i] == a[j]；
2. 删除 a[i..j] 这一整段（中间的元素无论是什么值都会被一起删除）；
3. 剩余元素保持原来的相对顺序拼接在一起。

注意：当 i == j 时，等价于单独删除一个元素，此时条件恒成立，算一次操作。

请你计算：把整个数组删空，最少需要多少次操作。

## 输入格式

第一行一个整数 n。

第二行 n 个整数 a[1], a[2], ..., a[n]。

## 输出格式

输出一个整数，表示最少操作次数。

## 样例

### 样例 1

输入：

```text
3
1 2 1
```

输出：

```text
1
```

解释：选择 i = 1, j = 3，两端都是 1，一次操作删除整个数组。

### 样例 2

输入：

```text
4
1 2 1 2
```

输出：

```text
1
```

解释：选择 i = 1, j = 4，两端都是 1，一次操作删除整个数组（中间元素一起被删）。

### 样例 3

输入：

```text
4
1 2 3 4
```

输出：

```text
4
```

解释：没有可配对的两端，只能逐个删除，需要 4 次操作。

## 数据范围

- 1 ≤ n ≤ 10^5
- -10^9 ≤ a[i] ≤ 10^9

## 注意事项

- 一次删除的区间只要求两端相同，中间元素没有限制。
- 删除后剩余部分会拼接，可能出现新的相邻相等元素；但任何“先删中间段再删外段”的方案都可以直接等价为一次删除更长的首尾相同区间，思考时注意不要重复计价。
- 元素值可能为负也可能很大，哈希存储时需要能处理所有取值。
