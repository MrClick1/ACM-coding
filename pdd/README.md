**排序 + 哈希**

### 复盘问题

- [ ] 多条件排序的优先级是否写对？
- [ ] 相同 ID 应该保留哪一条记录？
- [ ] 排名从 0 还是 1 开始？

## 2. 2026.03.29 Q1：货车运输

- [ ] 完成

**模拟 / 前缀状态**

沿途执行装货、卸货等操作，需要判断一段过程中载重是否一直满足限制。

## 3. 2026.04.12 Q1：区间覆盖

- [ ] 完成

### 核心模型

**差分数组 + 前缀和**

如果有大量区间 `[l, r]`，需要统计每个位置被覆盖多少次，可以使用：

```cpp
diff[l]++;
diff[r + 1]--;
```

然后前缀恢复覆盖次数。

### 训练重点

- 差分数组
- 前缀恢复
- `r + 1` 边界
- 从长业务题面识别“区间加”

---

## 4. 2026.06.16 Q1：特殊终点

- [ ] 完成

### 核心模型

**图 + 入度 / 出度**

不要一看到有向图就立刻写 BFS、DFS 或拓扑排序，先分析节点的 `indegree` 和 `outdegree`。

### 训练重点

**先找图的性质，再决定是否真的需要遍历算法。**

## 7. 2026.03.29 Q3：两个背包装奖品

- [ ] 完成

### 核心模型

**排序 + 双指针 + 后缀最大值**

```text
排序
↓
双指针找到每个起点对应的最长合法区间
↓
记录区间长度
↓
维护后缀最大值
↓
组合两个不相交区间
```

### 目标复杂度

`O(n log n)`

### 训练重点

**不要被题目名词诱导算法。**

看到“背包”不代表一定是 0/1 背包。

# 四、第三阶段：补拼多多高频模型

## 8. 2026.04.12 Q2：站位安排

- [ ] 完成

### 核心模型

**二分答案 + 贪心**

典型问题：

> 选 K 个位置，让相邻两个位置之间的最小距离尽可能大。

这是经典的“最大化最小值”。

### 思考流程

```text
答案是 d
↓
能不能选出 K 个点，使相邻距离 >= d？
↓
写 check(d)
↓
check(d) 具有单调性
↓
二分答案
```

典型代码结构：

```cpp
bool check(long long x) {
    // 判断答案至少为 x 是否可行
}
```

---

## 9. 2026.06.16 Q2：删除数组

- [ ] 完成

### 核心模型

**DP + 哈希优化**

先设计 `dp[i]`，如果转移需要寻找前面与 `a[i]` 相同的位置，暴力可能达到 `O(n²)`。

可以维护：

```text
value -> 该 value 对应的历史最优状态
```

使用哈希表优化。

### 训练重点

- 先写出正确但慢的 DP
- 找出重复枚举部分
- 用哈希 / 前缀最值优化状态转移

# 五、第四阶段：冲击 Q3 / Q4

## 10. 2026.06.16 Q3：K 次优惠最短路

- [ ] 完成

### 核心模型

**Dijkstra + 状态扩展 / 分层图**

普通最短路状态：

```cpp
dist[u]
```

如果最多有 `K` 次特殊操作：

```cpp
dist[u][used]
```

其中 `used` 表示已经使用多少次特殊机会。

也可以理解成把原图复制 `K+1` 层，然后在扩展状态图上跑 Dijkstra。

### 训练重点

当题目出现“最多可以使用 K 次……”时，要想到：

**把使用次数加入状态。**

# 六、第五阶段：去年提前批重点题

## 11. 2025.08.03 Q3：单峰序列最小代价

- [ ] 完成

### 核心模型

**左 DP + 右 DP + 枚举峰值**

```text
       peak
      /    \
     /      \
严格递增    严格递减
```

分别计算左侧递增代价和右侧递减代价，最后枚举峰值组合答案。

### 训练重点

- 前后缀 DP
- 把全局条件拆成左右两个局部条件
- 枚举中间连接点

---

## 12. 2025.08.03 Q4：补给包

- [ ] 完成

### 核心模型

**二分答案 + DAG DP / 贪心**

如果边只从编号小的节点指向编号大的节点，则天然构成 DAG。

假设最多允许持有 `x` 个补给，写：

```cpp
bool check(long long x)
```

判断是否能够到达终点。

如果 `x` 可行，通常 `x + 1` 也可行，因此具有单调性，可以二分答案。

### 训练重点

- 图结构识别
- DAG
- DP
- 贪心
- 二分答案

这道可以作为整套题单的 Boss 题。
