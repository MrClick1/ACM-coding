# Q1 - 赛道计时（差分数组 + 前缀和）

> ⚠️ 非官方原题：拼多多原题未公开。以下为根据题单概述与网络公开信息重构的练习版题目，样例与数据范围为构造值；若之后找到官方原题可替换本文件。
> 来源：题单见 [../../README.md](../../README.md)

## 题目描述

赛车场有 m 条赛道，编号 1..m。主办方收到 n 支测试队的预约，第 i 支队伍会在闭区间 [l_i, r_i] 内的每一条赛道上安排一次计时测试。也就是说，区间 [l_i, r_i] 覆盖的每一条赛道都会被这支队伍占用一次。

赛道 j 的“繁忙度”定义为覆盖它的测试区间数量。

主办方想给最繁忙的赛道优先检修。请你找出**繁忙度最高的赛道编号**；如果有多个赛道繁忙度相同且都是最高，输出其中编号最小的，并同时输出该最大繁忙度。

## 输入格式

第一行两个整数 n, m。

接下来 n 行，每行两个整数 l_i, r_i，表示一个测试区间，保证 1 ≤ l_i ≤ r_i ≤ m。

## 输出格式

输出一行两个整数：最大繁忙度 和 对应编号最小的赛道编号。

## 样例

### 样例 1

输入：

```text
3 6
1 3
2 5
3 6
```

输出：

```text
3 3
```

解释：赛道 1..6 的繁忙度依次为 1, 2, 3, 2, 2, 1。最大繁忙度为 3，对应赛道编号 3。

### 样例 2

输入：

```text
2 4
1 2
2 3
```

输出：

```text
2 2
```

解释：赛道 1..4 的繁忙度依次为 1, 2, 1, 0。最大繁忙度为 2，对应赛道编号 2。

## 数据范围

- 1 ≤ n, m ≤ 10^5
- 1 ≤ l_i ≤ r_i ≤ m

## 注意事项

- 区间为闭区间 [l_i, r_i]，两个端点都算覆盖。
- 可能有赛道没有被任何区间覆盖（繁忙度为 0），它们也要参与比较。
- 平局时取编号最小。
