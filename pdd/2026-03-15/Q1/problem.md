# Q1 - 直播排行榜（排序 + 哈希）

> ⚠️ 非官方原题：拼多多原题未公开。以下为根据题单概述与网络公开信息重构的练习版题目，样例与数据范围为构造值；若之后找到官方原题可替换本文件。
> 来源：题单见 [../../README.md](../../README.md)

## 题目描述

直播平台要给主播们生成一份“本周人气榜”。平台一共有 n 条直播记录，第 i 条记录包含三个整数：主播 ID id_i、该场直播的人气值 p_i、直播开始时间 t_i。

榜单规则如下：

1. 每个主播只保留一条**最佳记录**：人气值最高的一条；如果同一个人气值有多条，保留开始时间最早的一条。
2. 保留下来之后，所有主播按以下优先级排名：人气值高的排前面；人气值相同，开始时间早的排前面；仍相同，主播 ID 小的排前面。
3. 最终榜单需要按主播 ID 从小到大输出每个主播的排名（排名从 1 开始）。

请你计算最终榜单。

## 输入格式

第一行一个整数 n，表示直播记录条数。

接下来 n 行，每行三个整数 id_i, p_i, t_i，表示一条直播记录。

## 输出格式

第一行输出一个整数 m，表示保留的主播数量（去重后的主播数）。

接下来 m 行，每行两个整数，表示该主播的 ID 和最终排名，按主播 ID 从小到大输出。

## 样例

### 样例 1

输入：

```text
4
1001 500 10
1002 300 8
1001 400 12
1003 500 5
```

输出：

```text
3
1001 2
1002 3
1003 1
```

解释：主播 1001 有两条记录，保留人气最高的 (500, 10)；主播 1002 只有 (300, 8)；主播 1003 只有 (500, 5)。排名时 1003 与 1001 人气相同，1003 开始时间更早，因此 1003 第 1、1001 第 2、1002 第 3。

### 样例 2

输入：

```text
3
7 100 1
5 200 2
5 100 1
```

输出：

```text
2
5 1
7 2
```

解释：主播 5 有两条记录，保留人气最高的 (200, 2)；主播 7 保留 (100, 1)。按人气降序，5 在前，7 在后。

## 数据范围

- 1 ≤ n ≤ 10^5
- 1 ≤ id_i ≤ 10^9
- 0 ≤ p_i, t_i ≤ 10^9

## 注意事项

- 每个主播只保留一条记录：先比人气，人气相同比开始时间，与输入顺序无关。
- 排名从 1 开始，最终按主播 ID 升序输出。
- 需要建立 主播 ID → 最终排名 的映射。
