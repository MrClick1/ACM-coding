# Q3 - 单峰序列最小代价（双向 DP）

> ⚠️ 非官方原题：拼多多原题未公开。以下为根据题单概述与网络公开信息重构的练习版题目，样例与数据范围为构造值；若之后找到官方原题可替换本文件。
> 来源：题单见 [../../README.md](../../README.md)

## 题目描述

小 P 有一个长度为 n 的整数序列 a[1..n]。每次操作可以把**任意一个元素的值加 1**，花费 1 的代价（元素只能增加，不能减少）。

目标是让整个序列变成“单峰”：存在一个峰顶下标 k（1 ≤ k ≤ n），使得：

- a[1] < a[2] < ... < a[k]（前半部分严格递增）
- a[k] > a[k+1] > ... > a[n]（后半部分严格递减）

当 k = 1 时表示整体严格递减；当 k = n 时表示整体严格递增。

请你计算：使序列变成单峰所需的最小总操作次数。

## 输入格式

第一行一个整数 n。

第二行 n 个整数 a[1], a[2], ..., a[n]。

## 输出格式

输出一个整数，表示最小总操作次数。

## 样例

### 样例 1

输入：

```text
3
1 2 1
```

输出：

```text
0
```

解释：序列已经是单峰（1 < 2 > 1），无需操作。

### 样例 2

输入：

```text
3
3 2 3
```

输出：

```text
2
```

解释：把中间元素从 2 加到 4，得到 3 < 4 > 3，花费 2；任何小于 2 的代价都无法同时满足左增右减。

## 数据范围

- 1 ≤ n ≤ 10^5
- 0 ≤ a[i] ≤ 10^9

## 注意事项

- 只能增加，不能减少。
- 递增和递减都是**严格**的，相邻元素至少相差 1。
- 峰顶可以出现在端点，即允许整体单调。
- 可以分别考虑“使前缀严格递增的最小代价”和“使后缀严格递减的最小代价”，再枚举峰顶合并。
- 答案可能超过 32 位整数范围，注意使用 64 位类型。
